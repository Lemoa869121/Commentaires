Accès protégé

La clé d'accès est un jeton GitHub limité à ce dépôt, avec le droit « Contents : Read and write ». Seules les personnes qui ont cette clé peuvent modifier les listes et les textes. Comment créer la clé ?

Dépôt GitHub
Branche
Clé d'accès
  1. Sur GitHub : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : « Commentaires admin » ; expiration au choix.
  3. Repository access : Only select repositories → Commentaires.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Générez, copiez la clé et collez-la ici. Ne la partagez qu'avec les administrateurs.

Sans connexion à GitHub, vous pouvez aussi télécharger config.json et textes.json puis les déposer à la main dans le dossier data/ du dépôt.
